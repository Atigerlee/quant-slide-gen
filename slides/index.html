統計防禦線一：回測過度擬合機率 (PBO)
基於測度論的非參數化策略篩選檢驗框架
Mathematical Theory
  • 破解留出法：多重嘗試下，單一 Hold-out 必然失效。
  • 過度擬合定義：樣本內最優者，樣本外期望排名落入中位數以下。
  • CSCV 對稱切分：等分 S 塊對稱配對，映射至 Logit 空間積分。
PBO 數值積分與 Logit 映射
PBO = ∫ -∞ 0 f (λ) dλ , λc = ln ( ω¯c 1-ω¯c )

實務警戒：PBO>0.05 即應拒絕策略

統計防禦線二：通縮夏普比率 (DSR)
矯正選擇偏差、非高斯偏態與試驗次數膨脹
Statistical Rigor
  • 極值膨脹校正：最大夏普隨試驗數 N 呈對數邊際虛增。
  • DSR 顯著性檢定：納入樣本長度與偏態峰態修正選擇偏差。
  • 1/e 最優停止法則：評估前 37% 策略確立基準，超越者即停。
通縮夏普比率公式 (DSR)
DSR = Z [ (SR^-SR^0) T-1 1 - γ^3SR^ + γ^4-1 4 SR^2 ]

若 DSR<0.95，高夏普仍不可信
